# `d_variation` — covariate-count sweep for the Do-PFN case studies

Generated by `generation_d.py`, which generalizes the fixed DAG templates in
`case_study/generation.py` so the number of **observed covariates** `d` is a free
parameter.

## Layout

```
d_variation/
  manifest.json                    # sweep index across shifts
  generation_d.py                  # the generator
  shift{+2,-2,+5,-5}/
    d{K}/                          # K in {2,3,5,10,20,30,40,50}
      manifest.json                # per-d manifest, incl. feature_names per case
      cate_ate_shift{S}_d{K}.png   # + .json sidecar
      <Case>/N{50,100,250,500,1000}/<Case>_{0..99}.npz
  shift0/                          # legacy beta=0 sweep, contexts 200/500/1000
```

**96,000 `.npz`** across the four shifts (4 x 8 d x 6 cases x 5 context sizes x
100 realizations), 4.2 GB. `seed_base=0` throughout.

`shift0/` is the earlier beta=0 sweep, kept as-is. Note it uses the OLD context
sizes (200/500/1000), so it is not directly stackable with the four shift roots.
Regenerate it at the new contexts with:

```bash
python case_study/d_variation/generation_d.py --out-dir case_study/d_variation/shift0 \
    --context-sizes 50 100 250 500 1000 --cate-shift 0 --overwrite
```

### Shifts are the SAME SCM, only beta differs

Seeds derive from `(seed_base, d, case_idx, N, r, attempt)` and do **not**
include `cate_shift`. So a given (d, case, N, realization) is the identical
sampled SCM in every shift root — the comparison across beta is controlled.
`--cate-shift` injects `beta*T` only where a direct `T -> Y` edge exists, so
Backdoor and Frontdoor are **bit-identical across all four shifts**. Verified
ATE at d=10, N=1000:

| case | β=+2 | β=−2 | β=+5 | β=−5 |
|---|---|---|---|---|
| `Observed_Confounder` | +2.021 | −1.979 | +5.021 | −4.979 |
| `Observed_Mediator` | +2.068 | −1.932 | +5.068 | −4.932 |
| `Observed_Mediator_and_Confounder` | +2.026 | −1.974 | +5.026 | −4.974 |
| `Unobserved_Confounder` | +1.995 | −2.005 | +4.995 | −5.005 |
| `Backdoor_Criterion` | +0.008 | +0.008 | +0.008 | +0.008 |
| `Frontdoor_Criterion` | +0.003 | +0.003 | +0.003 | +0.003 |

## How `d` scales — causal-role scaling

The single confounder `C` becomes `C1..Ck` (every one a genuine confounder into
both `T` and `Y`); the single observed mediator `M` becomes `M1..Mj` (every one on
a `T -> M -> Y` path).

**Hidden nodes scale at `h = max(1, d // 10)`** — one per 10 covariates, floored
at 1 (the floor is required: Backdoor/Frontdoor need at least one mediator and
`Unobserved_Confounder` at least one `U` for the case to be well-defined):

| d | 2 | 3 | 5 | 10 | 20 | 30 | 40 | 50 |
|---|---|---|---|---|---|---|---|---|
| hidden nodes `h` | 1 | 1 | 1 | 1 | 2 | 3 | 4 | 5 |

Hidden nodes are **not** covariates, so `X` stays `(N, d)` at every `d`.

| Case | Structure at covariate count `d` |
|---|---|
| `Observed_Confounder` | `C1..Cd -> T`, `C1..Cd -> Y`, `T -> Y` |
| `Backdoor_Criterion` | `C1..Cd -> T/Y`, `T -> M1..Mh(hidden) -> Y`, no direct `T -> Y` |
| `Observed_Mediator` | `T` exogenous, `T -> M1..Md -> Y`, `T -> Y` |
| `Observed_Mediator_and_Confounder` | `C1..Ck -> T/Y`, `T -> M1..Mj -> Y`, `T -> Y`, `k=ceil(d/2)`, `j=floor(d/2)` |
| `Unobserved_Confounder` | `U1..Uh(hidden) + C1..Cd -> T/Y`, `T -> Y` |
| `Frontdoor_Criterion` | same as Backdoor |

Every case keeps its identification structure at every `d`. At each case's
baseline `d` (1, or 2 for `Observed_Mediator_and_Confounder`) the builders reduce
to *exactly* the templates in `generation.py` — verified by structural comparison.

## Known consequence: effect size shrinks as `d` grows

Weight init is Kaiming fan-in (`bound = 1/sqrt(#parents)`), inherited unchanged
from the baseline generator. As `Y` gains parents, the weight on `T` shrinks like
`1/sqrt(fan_in)`, so **the treatment effect attenuates with `d`**. sd of true
CATE, pooled over 100 realizations at N=1000:

| Case | d=2 | d=5 | d=10 | d=20 | d=30 | d=40 | d=50 |
|---|---|---|---|---|---|---|---|
| `Observed_Confounder` | 0.349 | 0.221 | 0.215 | 0.173 | 0.148 | 0.108 | 0.095 |
| `Backdoor_Criterion` | 0.142 | 0.142 | 0.113 | 0.109 | 0.119 | 0.117 | 0.093 |
| `Observed_Mediator` | 0.335 | 0.270 | 0.213 | 0.277 | 0.192 | 0.235 | 0.234 |
| `Observed_Mediator_and_Confounder` | 0.350 | 0.310 | 0.291 | 0.209 | 0.208 | 0.262 | 0.229 |
| `Unobserved_Confounder` | 0.361 | 0.275 | 0.193 | 0.165 | 0.138 | 0.129 | 0.103 |
| `Frontdoor_Criterion` | 0.236 | 0.154 | 0.099 | 0.118 | 0.113 | 0.144 | 0.107 |

Attenuation is steepest where all `d` covariates pile onto `Y` as confounders
(`Observed_Confounder`, `Unobserved_Confounder`: ~3.5x from d=2 to d=50). The
mediated cases hold up better — extra hidden mediators add `T -> M -> Y` paths
that partly offset the fan-in shrinkage.

**Implication for analysis:** raw PEHE / L1 will *improve* with `d` partly because
the estimand itself is smaller. Normalize before comparing across `d` — e.g. report
`PEHE / sd(true_cate)`, or a normalized RMSE.

If you instead want a treatment effect of constant magnitude at every `d`, pass
`--cate-shift BETA`. That injects `BETA * T` additively into the outcome *after*
the activation, so it is not attenuated by the fan-in bound. Note it only applies
to the four cases with a direct `T -> Y` edge (Backdoor/Frontdoor stay at 0).

## CATE / ATE distribution plots

Each `d{K}/` carries `cate_ate_d{K}.png` (+ a `.json` sidecar with per-cell
mean/sd). Same figure as `case_study/cate_distributions/`: one row per case, one
column per context size; filled orange = per-unit CATE pooled over all 100
realizations, dark-green outline = per-dataset ATE (one value per realization).

Regenerate with:

```bash
for d in 2 3 5 10 20 30 40 50; do
  PYTHONPATH=case_study python3 case_study/cate_distributions/plot_distributions.py \
    --data-dir case_study/d_variation/d$d \
    --out case_study/d_variation/d$d/cate_ate_d$d.png \
    --title-note "d = $d covariates"
done
```

**Caveat when comparing figures across `d`:** each figure picks its own x-range
from its own data (0.5–99.5th percentile per case). At d=2 `Observed_Confounder`
spans about ±1.5; at d=50 it spans about ±0.4. The distributions therefore look
similarly wide on the page even though the effect has shrunk ~3.5x. Read the
axis numbers, or use the `.json` sidecars, rather than eyeballing the shapes.

## Use with the existing eval

Each `d{K}` directory is a drop-in `CASE_STUDY_DATA_ROOT` for
`case_study/eval/scm_case_study_dataset.py`:

```bash
export CASE_STUDY_DATA_ROOT=case_study/d_variation/d10
export CASE_STUDY_N=200
python case_study/eval/do_pfn.py        # etc.
```

## Regenerating

```bash
python case_study/d_variation/generation_d.py \
    --out-dir case_study/d_variation \
    --n-covariates 2 3 5 10 20 30 40 50 \
    --context-sizes 200 500 1000 \
    --n-realizations 100 --seed-base 0
```

Seeds derive from `SeedSequence([seed_base, d, case_idx, N, r, attempt])`, so every
`(d, case, N, realization)` cell is an independent reproducible stream, and adding
a new `d` never disturbs existing ones. Re-running skips existing files unless
`--overwrite` is passed.
